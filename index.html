Dúvidas frequentes

Preciso pagar?

Não. É um projeto acadêmico: não há cobrança e a reprodução dos filmes é simulada.

Onde meus dados ficam salvos?

No Local Storage do seu navegador. Nada é enviado a um servidor.

Posso ter mais de uma conta?

Neste projeto, cada navegador guarda uma conta. Criar outra substitui a anterior.
